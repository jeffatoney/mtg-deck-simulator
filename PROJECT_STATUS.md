# MTG Deck Simulator Project Status

Current project state is no longer maintained manually in this file.

Use the repository-generated handoff instead:

- Protocol on `main`: `docs/audit/handoff/PROTOCOL.md`
- Machine-owned branch: `handoff/current`
- Human-readable handoff: `docs/audit/handoff/CURRENT_HANDOFF.md`
- Machine-readable handoff: `docs/audit/handoff/CURRENT_HANDOFF.json`

The handoff is regenerated from the exact `main` commit and GitHub machine state after CI completes.
Independent reviewers must still refresh GitHub and verify the handoff subject commit before relying on it.

Do not add mutable SHAs, CI run numbers, PR heads, authorization state, or diagnostic counts to this file.
Those values belong in the generated handoff or their authoritative machine-readable source records.
